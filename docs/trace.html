Where did those
bitcoins go?

Trace publicly observable transaction paths from any Bitcoin wallet using an address or a TXID. No BitBox, Ledger, Trezor, exchange, or wallet provider is required.

Read-only. Do not enter a seed phrase, private key, password, xpub or descriptor. This page never signs or broadcasts transactions. It queries a public explorer, which can see the addresses and TXIDs you search. An address does not represent an entire wallet.

Data provider: mempool.space public API. Explorer data is not independently verified by this page. Rate limiting, unconfirmed transactions and chain reorganizations can change results.

Ready to search. No account or wallet connection needed.

What these results mean

OBSERVED The explorer reports that a specific output was spent by a specific transaction. This verifies a public linkage, not the recipient's identity.

AMBIGUOUS A spending transaction has multiple inputs. Its outputs cannot be assigned uniquely to the selected input by reading the blockchain alone.

NOT RESOLVED The search limit was reached, an output is unspent according to the explorer, or information is unavailable. Neither an unspent status nor a path proves that an address belongs to a thief.

Custodial exchange ledgers, off-chain transfers, cross-chain swaps and ownership cannot be inferred reliably from the Bitcoin ledger alone. No stolen-funds claim is adjudicated; the sample TXID is for technical illustration only. Do not use the report to blacklist or accuse an unrelated holder.

Open-source prototype · no cookies or analytics · no private-key access · no guaranteed tracing through CoinJoin, custodial services or cross-chain movements. Review and feedback.
